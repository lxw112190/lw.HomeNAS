# v1.3.1：网页时间线与手机连接样式

准备版本：Windows / Android **1.3.1**，APK **versionCode24**；包名、固定签名和 **nativeApi14** 保持不变。

## 改进

- 时间线日期输入框原先继承全局 `label input` 的上、下外边距，导致日期、年份、月份和按钮错位。现在限定筛选区的表单间距，统一40px高度、字体及标签间距。
- 筛选栏使用独立卡片和网格：桌面六个控件对齐成一行，窗口较窄时四个条件和操作按钮分行，小屏采用两列；提示独占一行。“筛选”为绿色主按钮，“全部日期”为次按钮。
- “存储与设置 → 连接手机”的地址下拉框统一40px高度、字体、边框、圆角、内边距及箭头；桌面最大640px，窄屏随容器收缩，长地址省略显示，下面保留完整地址。键盘选择和焦点提示继续可用。

本轮仅调整Web样式和发布版本信息；照片排序、日期范围、账号、数据库及APK业务逻辑保持原有行为。

## 本机验证

- Windows Release实际编译，运行EXE返回1.3.1；增量运行目录web已同步。
- 实际浏览器：默认桌面六个控件均40px高且顶部一致、外边距为0；1024px按预期分行；320px页面宽度与滚动宽度一致，没有横向溢出。
- 用隔离合成照片验证选择2015年仅显示对应照片，“全部日期”恢复列表。
- 实际切换手机连接地址，二维码与完整地址同步变化。320px下连接下拉框宽223px、高40px，长地址省略，页面没有横向溢出；浏览器未记录控制台错误。
- 时间线接口9项、生产分页DOM35项、日期/连接DOM、发布工具35项，以及版本/协议、Android主机布局与工作流结构检查通过。
- 截图仅保存在忽略目录：`test-results/timeline-layout-v1.3.1-desktop.png`、`test-results/phone-connection-v1.3.1-desktop.png`。未使用真实照片或资料库。

新APK编译、Lint/JVM、模拟器及同提交完整ZIP仍需本轮CI验证，本机网页与工具检查不能替代。
