# APK选图性能与资料库简化

准备版本：1.3.2 / Android code25 / nativeApi14，包名与固定签名不变。

## 选图性能

发现每次单张勾选、每次原生入队状态轮询都会更新所有已展开日期的缩略图；月份和日期半选状态还重复扫描全部选择/排除数组。

- DailySelection按选择变更版本缓存日期/月份半选索引，未变更时不重新构造数组。
- 单张勾选只更新当前日期头部、月份状态与汇总，保留浏览器已更新的复选框，不遍历图片网格。
- 相同入队状态轮询只更新进度；状态转换时才更新选择控件，运行中禁用、停止重试和完成回执保留。
- 同时仅展开一天缩略图，切换日期释放其他日期图片DOM，选择及排除规则保留。天内“更多照片”仍分页追加；收起重开从首批查看。
- 收起或被替换日期的迟到响应不再重新插入图片。

这些修改减少已确认的前端重复工作，不能判定某一手机卡顿的全部原因。原生媒体查询、系统选择器及解码开销还需新APK真机复测；不降低READY、校验或续传要求。

## 资料库

保留搜索框、文件夹/时间线/主题图集标签、位置导航和选择入口。文件类型、刷新、新建/编辑/添加内容、日期条件集中到默认收起的“筛选与整理”，复用原控件、ID及事件，不复制选择状态。

返回键优先关闭弹窗，再收起面板，然后执行原目录/页面返回。批量工具只在选择模式显示。网页布局不变，共享分类控制器未分叉。

## 升级

新APK首次启动按versionCode清除旧界面的active/previous/staged指针，显示新版内置页面，避免同协议旧资源遮住修复。以后不重复清理，兼容签名资源仍可使用。只操作client-maintenance偏好，不修改账号、队列或原件；nativeApi保持14。

- 选择模型：全选/月/日、排除、后续分页、5000项索引重复复用及范围变更失效；入队/停止、目标目录、并发显示回归通过。
- 备份中心、日期/连接DOM、生产资料库分页35项；Android主机23项、发布工具35项及版本/协议/工作流检查通过。
- Windows Release实际编译。浏览器加载实际APK页与模拟桥，核对390px/320px布局、面板、日期条件及返回；320px无横向溢出。模拟5505项全选显示正常，这是范围选择模拟，不是5505张真实媒体入队或手机速度验收。
