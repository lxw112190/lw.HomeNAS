# 公网IP与云服务器NAT测试

0.2.2-dev新增 `allow_external_hosts`。此前Host只接受电脑网卡IPv4和localhost，云服务器公网IP可能由NAT映射，未出现在网卡列表，因而返回HOST_REJECTED。旧版需要更新EXE才能识别新字段。

## 8080启动示例

停止旧程序，更新NasServer.exe，保留原有data和config。编辑正在运行的EXE旁 `config/server.json`，只修改/添加下面两项，其余字段保留：

```json
"http_port": 8080,
"allow_external_hosts": true
```

在部署包目录启动：

```powershell
.\NasServer.exe --allow-insecure-lan
```

或明确指定配置文件：

```powershell
.\NasServer.exe --config .\config\server.json --allow-insecure-lan
```

随后访问 `http://公网IP:8080/`；`/api/v1/server` 返回版本 `0.2.2-dev` 和 `allow_external_hosts: true` 可确认运行的是新版和正确配置。无需维护白名单，也无需把公网IP绑到系统网卡。配置为布尔值true，不能写成字符串"true"。

如果使用Windows服务，配置文件位置相同。已安装服务执行 `deploy/configure_http_service.bat`，运行中的服务会停止再启动；原来停止的需再执行start_service.bat。首次安装使用install_http_service.bat。仅运行start_service不会重启已在运行的服务，修改配置后需重启。

此开关只解除Host必须属于本机网卡的限制，不会修改监听端口或自动调整云安全组/Windows防火墙，也不取消用户名密码登录。HTTP监听局域网/公网仍需显式开启 `--allow-insecure-lan`。默认false，旧配置缺省时也保持原有局域网行为。

本轮按功能优先提供公网直连HTTP测试；HTTP中的账号密码和文件未加密。域名证书、反向代理的转发头信任与外网完整部署后续再完善。

验证使用独立本地库和公网/DNS Host请求头，覆盖配置开关、网页、Cookie登录、上传、下载、退出及原有同源行为，不连接或更改用户公网服务器。没有将本地模拟测试写成公网部署验收。
