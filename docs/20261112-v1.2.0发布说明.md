# lw.HomeNAS v1.2.0 发布与升级说明

日期：2026-11-12。源码发布准备版本1.2.0，Android versionCode21、nativeApi12。包名与既有固定签名不变。此文件不是已完成线上发布的声明。

## 本次变化

- Web上传在选择文件前可选择已有文件夹或直接新建，不选仍使用默认文件夹。任务入队固定目标，切换目录不改变既有任务；跨目录相同内容复用原件并补关联，历史任务展示目录。
- 完整Windows ZIP的client-release包含APK和清单。前台或服务启动自动校验、发布APK及可选签名页面资源；登录页无需登录即可下载。首次部署不再要求手动运行APK导入脚本。
- 保留已发布新版，不按旧部署包降级；同版本不同内容拒绝覆盖。管理员撤下状态持久化，重启不重新上架同版；错误包不阻止NAS启动。
- README增加作者、QQ、QQ群与支持维护原图，图片随完整部署包提供。

## 首次使用

1. 下载新的Windows完整ZIP并完整解压，保留client-release目录。
2. 双击根目录启动命令或运行NasServer.exe；需要开机后台运行时，以管理员身份执行deploy/install-service.bat，安装后自动启动。
3. 手机访问电脑的HTTP端口（默认8787，可在config/server.json修改），从登录页下载App并安装。
4. 全新部署管理员默认admin/admin123，登录后修改。默认allow_insecure_lan与allow_external_hosts为true，按实际网络需求调整。

## 从旧版升级

停止旧服务，备份并保留原config与data，替换程序、web、deploy、client-release等发布文件，再启动。不要用新包默认config覆盖已有端口和数据路径。账号、原件、目录与服务器续传数据保留。

手机安装固定签名的新code21 APK可覆盖同签名旧版；不要为普通升级先卸载应用，以免丢失手机待上传队列。不同历史临时签名的APK不保证可覆盖安装。系统安装确认仍由用户完成。
