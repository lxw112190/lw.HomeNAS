# 多级目录与权限继承（1.4.0）

本轮开发与验证完成于2026年11月14—15日。源码版本为1.4.0，Android versionCode为26，原生资源协议为15；固定APK签名不变。Windows已实际编译，新的Android编译、Robolectric、模拟器及同提交完整部署包仍须通过CI，真机效果待安装新APK确认。本文不代表已经发布。

## 怎么用

资料库默认进入“文件夹”。点击目录逐级进入，用顶部位置导航返回祖先；手机返回键也逐级返回。进入可管理的目录后，使用“新建子文件夹”“目录权限”“移动目录”。手机沿用折叠的整理入口。

- 最多16层，从一级目录算起；逐级分页浏览，不会一次展开整棵树。
- 上传目标显示完整路径，队列入队后固定目标ID，修改偏好仅影响新任务。
- “本层”数量与容量只计算当前目录直接关联且本人有权访问的活动文件，不包含后代；子目录数量同样按权限过滤。
- 移动目录保留ID、后代和原件位置。禁止移入自身或下级，禁止超过16层；只有空目录可以删除，回收站文件关联也算非空。

## 权限规则

新建一级目录默认为“仅所有者”，子目录默认“继承父目录”。

| 模式或级别 | 效果 |
| --- | --- |
| 继承父目录 | 采用父目录的有效权限，仅用于子目录 |
| 仅所有者 | 限目录所有者和服务器管理员 |
| 指定成员 | 分别设置只读、可整理、管理；其他成员不授权 |
| 所有账号只读 | 一级对登录账号只读；子目录仅在父级可见范围内只读 |
| 只读（1） | 浏览、预览、下载本人可见资料 |
| 可整理（2） | 写入和整理资料；旧共享默认目录仍保留文件上传归属限制 |
| 管理（3） | 另可创建子目录、改名、移动目录、调整权限和删除空目录 |

有效权限取沿途祖先限制的最小值，再受账号角色限制：viewer始终只读。子目录不能扩大父目录权限；超过父级的显式成员授权会拒绝，整次修改回滚。所有者在本目录有管理权，但仍受祖先限制。受委托管理者不能通过保存权限误删自己的管理权，需所有者或服务器管理员处理。

服务器管理员始终可访问全库。目录权限不是磁盘加密，不能阻止拥有服务器磁盘访问权的人读取原件。已经下载的内容无法撤回；撤权前已经开始的媒体流可能继续完成，后续请求重新检查权限。

## 旧资料和多目录引用

升级不会把旧共享目录自动改成私有：旧目录保留兼容共享策略，默认文件夹仍兼容旧客户端，不能改名、删除或设私有。建议确认成员需求后逐个调整普通旧目录。

现有多目录引用模型保留，**同一文件的有效权限取所有所属目录的交集**。把共享文件加入私有目录，可能使其他引用中的同一文件也不可见。目录移动、权限修改、添加/移除关联均有影响提示与确认；图集不会额外授予访问权，其封面、成员与数量按权限过滤。图集本身仍为共享专题元数据，不提供独立图集ACL。

为避免私有文件被跨目录摘要命中泄露，上传去重改为复用“同一目标目录中本人可以访问”的已入库文件。不同目标目录上传相同内容，产生独立资料记录和独立物理原件；旧引用不拆分。本轮没有实现独立文件条目与共享物理blob的完整迁移，不能把各个引用理解为独立授权，也不承诺跨目录节省磁盘空间。

## 撤权、删除目标与续传

目标被删除或撤权后停止上传，**不会自动改存共享默认目录**。旧任务保留原folder_id和确认偏移；用户可重新选择目标并建立新任务。

创建任务、写块前、块确认事务、完成请求和最终入库事务均检查权限。若传输块正文期间撤权，当前块回滚至原确认长度，数据库偏移不前移；恢复权限后可重传。VERIFYING/COMMITTING任务保留字节和中间状态，恢复权限后查询/完成请求可重新排队核验。已删除目标的UPLOADING任务仍可由本人取消，不触及原件。

列表、时间线、日期汇总、统计、原件与Range、缩略图、元数据、导出、图集和回收站均检查可见性。分页前过滤，不能靠另一条读取接口绕过权限。失去目标访问权的历史任务隐藏目录后来改的新名称；来源检查返回INACCESSIBLE且不暴露原件ID。

## 数据升级与备份

新增folders.parent_id、folders.policy、folder_acl和folder_tree。祖先索引在事务中重建并检查深度、循环和无效父目录；同父子目录名称不分创建者去重，一级旧命名保留按所有者区分的规则。

在线元数据快照和完整迁移包含目录树及成员授权。元数据快照仍不含原件；恢复旧快照也恢复当时分类与权限，应重新核对成员。不要用旧版服务打开升级后的库。上线前建议停服保留完整独立副本。
