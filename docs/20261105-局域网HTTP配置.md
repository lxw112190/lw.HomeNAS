# 局域网 HTTP 配置（电脑端 0.3.2）

按用户要求，将 `--allow-insecure-lan` 对应行为加入配置，默认开启。配置项沿用其他字段的下划线命名：

```json
"allow_insecure_lan": true
```

此项位于 EXE 旁 `config/server.json`。前台与 Windows 服务都读取该配置；旧配置缺少此项时也默认 true。修改后重启 NAS 生效，不自动重启用户的运行实例。

| 配置及参数 | HTTP 监听 |
| --- | --- |
| true，无覆盖参数 | 0.0.0.0，电脑与局域网可访问 |
| false，无覆盖参数 | 127.0.0.1，仅本机 |
| 任意配置，加 `--allow-insecure-lan` | 强制开启局域网 HTTP |
| 任意配置，加 `--no-allow-insecure-lan` | 强制 HTTP 仅本机 |

显式命令行参数优先；原有 `--allow-insecure-lan` 保持兼容。普通启动/安装脚本跟随配置；HTTP 专用脚本显式开启，`configure_https_service.bat` 现在显式关闭局域网 HTTP，避免配置默认 true 导致切换失效。修改配置本身不改变端口、防火墙、HTTPS 或账号。

如果旧服务启动参数仍带 `--allow-insecure-lan`，单改 JSON 为 false 不会盖过它；运行对应的 HTTPS 配置脚本，或移除强制开启参数。服务脚本的查看计划可显示实际生效的 `AllowInsecureLan`，不安装服务也能检查。

`allow_external_hosts` 控制 Host/IP 接受范围，与监听开关分开。完整部署包这两项均为 true；HTTP 默认端口仍为 8787，HTTPS 9443 同时保留。首次管理员 admin/admin123、已有密码不重置的行为保持原样。APK 仍使用已核验的 CI9 0.6.2-dev/code9，不需要重装或重新编译安卓。
