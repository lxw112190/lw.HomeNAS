# lw.HomeNAS v1.5.1

本版包含 Windows 服务端、Web 管理界面及 Android 客户端。Android versionCode 为34，nativeApi 为15，继续使用原有持久签名。

## 更新内容

- 新增“照片与文件 → 重复文件”：按SHA256与文件大小查找内容完全相同的独立原件，支持当前账号可见全库、当前文件夹及子目录，默认查照片，也可查视频和其他文件。
- 重复组分页展示缩略图、完整目录、目录授权类型及图集引用提示。推荐保留最早入库的一份，可手动更换；清理项需要明确勾选，支持跨页选择，每批最多20份。
- 清理前完整校验保留项及所选副本，重新检查权限、状态和关联；原件异常、权限不足或预览过期时整批拒绝。清理只移入回收站，可恢复原关联，不自动转移引用，也不修改手机文件。
- 上传显示重复跳过统计、已有文件名称及目录入口。相同目标已有相同内容时跳过传输；不同目录仍保留独立副本与原有权限范围。
- Web全局统一下拉框高度、圆角、边框、背景、箭头、键盘焦点与禁用状态，并适配窄屏。
- 修复Web与Android共享控制器漏同步导致的CI检查失败，将新增查重与界面回归加入Windows发布验证。

## 使用与升级

升级前停止旧服务并保留独立备份，保留已有config与data目录；将新程序及完整web资源部署到原安装位置后重新启动。Android可安装同签名新APK覆盖升级，账号与队列继续保留。

本功能识别字节内容完全相同的文件；压缩、裁剪、添加水印或修改元数据后的相似照片不会归为一组。同一原件的多处逻辑关联不重复计数，超过16个目录或图集关联的文件需人工整理。

移入回收站暂不释放空间；彻底删除仍需管理员在回收站单独确认。数据库快照不包含照片/视频原件，同盘快照不替代独立备份。

正式附件以本标签对应CI完成Windows测试、Android构建与模拟器检查、同提交完整部署包验收后公开的Release为准；自动验收不代表所有Android设备均已实测。
