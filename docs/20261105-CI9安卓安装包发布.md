## 新部署

1. 完整解压，运行 `deploy/import_android.bat`，导入随包 APK 和签名界面资源 r6。
2. 家庭内网 HTTP 使用 `deploy/start_console_http.bat`；默认端口 8787，其他服务/防火墙入口见 [deploy 说明](../deploy/README.md)。
3. 浏览器访问电脑地址，首页和登录页可以下载本次 APK。
4. 全新数据目录首次账号为 **admin / admin123**，登录后在“存储与设置”修改密码。

包内默认 `allow_external_hosts: true`。它不自动修改监听模式、端口或防火墙；需要内网 HTTP 仍运行对应 HTTP 入口。所有运行路径按配置目录解析。

已包含 FFmpeg 7.1、许可、来源记录和上游源码归档，使用相对路径 `../tools/ffmpeg/ffmpeg.exe`，无需设置 PATH。视频入库后后台逐个生成封面；封面失败不影响原件。该功能不对完整视频做兼容转码。

## 更新已有服务器及手机

先停止 NAS，保留原 config/data，再更新程序、web、deploy、client-release 和 tools/ffmpeg。将原配置的 `ffmpeg_path` 设为上述相对路径或沿用程序默认；保留原端口、数据路径及其他设置。执行导入后重新启动。已有账号密码不会被初始固定密码覆盖。

CI9 证书与 CI7 不同，不能直接覆盖旧 APK。旧手机先完成待上传任务；卸载会清除本机队列、授权和登录，电脑原件保留。诊断 ZIP 不含可恢复队列。固定签名需要持续使用同一份 JKS Secrets，不能从 APK 反推出原私钥，见 [Android 签名说明](../android/README.md#签名与覆盖升级)。

新 APK 已内置最新页面，无须先更新资源；原先激活过旧资源的手机，可检查更新、更新至 r6 后重新打开。旧原生 APK 即使更新网页，也不能获得新原生能力。
